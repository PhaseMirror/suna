## Claim
"Kortix is the open-source AI Management System."

## Mirror
Kortix is open-source software.

## Dissonance
The repository is governed by the Elastic License 2.0 (ELv2). ELv2 is not an Open Source Initiative (OSI) approved license. The license prohibits providing the software to third parties as a managed service and forbids circumventing license key functionality. The marketing tagline asserts "open source" while the legal mechanism enforces source-available commercial restrictions.

## Phase
- **Action:** Update all root documentation, manifesto references, and comms guidelines to state "open-code under Elastic License 2.0" or explicitly qualify source availability without unhedged OSI-implied terminology.
- **Owner:** Comms Owner
- **Metric:** 100% of license mentions in root docs cite ELv2 terms; 0 unhedged "open source" claims in public positioning copy.
